# wvb-ffi

UniFFI bindings for `wvb`, projected into Kotlin (Android) and Swift (Apple).

The SDK for the android and ios are separated from this repository.

- [webview-bundle-android](https://github.com/webview-bundle/webview-bundle-android)
- [webview-bundle-ios](https://github.com/webview-bundle/webview-bundle-ios)

See the documentation:

- Android : https://wvb.dev/docs/guide/android
- iOS : https://wvb.dev/docs/guide/ios
