# @wvb/deno

Deno bindings and desktop integration for WebView Bundle.

Desktop window bindings require Deno 2.9.4 or later.

This feature is supported on an experimental basis and may be subject to change in the future.

```ts
// Core bindings
import { loadLib, Source } from '@wvb/deno';

// Desktop integration
import { webviewBundle } from '@wvb/deno/desktop';
```

For more details, see the [documentation](https://wvb.dev/docs/guide/deno-desktop).
